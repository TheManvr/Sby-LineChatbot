# การเพิ่มหัวข้อข้อมูลโรงเรียน

ระบบอ่านไฟล์ JSON ทุกไฟล์ใน `data/topics/` ตอนเริ่มเซิร์ฟเวอร์ จึงเพิ่มหัวข้อใหม่ได้โดยไม่ต้องแก้ flow ของ LINE webhook

ไฟล์หัวข้อใหม่ต้องมีข้อมูลอย่างน้อยดังนี้:

- `id`, `title`, `enabled`, `scope`
- `aliases` สำหรับระบุชื่อหัวข้อ
- `source` สำหรับชื่อเอกสาร จำนวนหน้า และ checksum
- `entries` โดยแต่ละรายการมี `id`, `title`, `sourcePages`, `keywords`, `answer`

คำตอบใน `answer` ต้องตรวจสอบกับเอกสารต้นทางแล้ว ห้ามใส่ข้อความที่คาดเดาเอง ระบบจะค้น entry ที่ตรงกับคำถามก่อน และส่งเฉพาะ entry ที่เกี่ยวข้องให้ AI เรียบเรียง เพื่อลดการตอบนอกข้อมูล

หลังเพิ่มหรือแก้ข้อมูล ให้รัน:

```powershell
npm run check:knowledge
npm test
```

หากต้องการเปิดหัวข้อใหม่ให้ผู้ใช้จริง ควรเพิ่มกรณีทดสอบทั้งคำถามที่ควรตอบและคำถามนอกขอบเขตใน `test/retriever.test.js` ด้วย
